## Com classificar

Un recurs va a **una** secció principal. Només es duplica si és realment híbrid (ex. SkillSpector = AI + SAST).

| Si és… | Va a… |
| :--- | :--- |
| Recon, exploits, C2, BAS, AD ofensiu | [Offensive](sections/offensive-security-pentesting-bug-bounty.md) |
| Skills, MCP, agents, LLM de cyber | [AI i Agents](sections/ai.md) |
| Dominis, leaks, CTI, people search | [OSINT](sections/osint-threat-intelligence.md) |
| SAST, secrets, SCA, SBOM | [Code Analysis](sections/code-analysis-sast.md) |
| AWS/Azure/GCP audit o exploit cloud | [Cloud](sections/cloud-security.md) |
| Protocols industrials, S7, incidents OT | [ICS/OT](sections/ics-ot.md) |
| Hardening, WAF, TLS, vuln scanner de host | [Infra](sections/infrastructure-linux-hardening.md) |
| PCAP, IDS, IR, metadades | [Xarxa i forense](sections/network-forensics.md) |
| Bloqueig, privacitat, sobirania | [Privacy](sections/digital-sovereignty-privacy-self-defense.md) |
